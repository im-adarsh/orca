For one consistent look

Every theme gives the frame, project rail, file explorer, tabs, and floating panels a separate shade. Its main accent identifies selections and focus, while editor and terminal surfaces match. Use the same app and terminal theme name. Set background opacity and active/inactive pane opacity to 100%, choose Default for Left Sidebar Appearance, and clear terminal Color Overrides in both modes.

Settings to reuse on each laptop

Interface & editor

  • IDE font: Inter Variable or Inter
  • Editor font: JetBrains Mono
  • Left Sidebar Appearance: Default
  • Minimap: Off
  • Word wrap: On

Terminal

  • Font: JetBrains Mono, 14 px
  • Weight: 400; bold: 700
  • Line height: 1.2
  • All background/pane opacity: 100%
  • Cursor: bar; blink: On
  • Window blur: Off

Chat & navigation

  • Match terminal interface: On
  • Chat width: Wide
  • Chat contrast: 100%
  • Project: Cmd/Ctrl+Alt+1
  • Git: Cmd/Ctrl+Alt+9
  • Search: Cmd/Ctrl+Alt+Shift+F

Theme pairing

  1. In Appearance, select the app theme you want.
  2. Enable separate light and dark terminal themes.
  3. Select in the terminal slot to match the palette above.
  4. After updating the plugin, reselect the terminal theme to refresh its saved palette. Empty color override fields mean “use the selected theme”; a black empty picker swatch does not mean the theme is black.

Install on another laptop

Add this source under Settings → Plugins → Marketplace sources:

https://github.com/im-adarsh/orca.git

Requires Orca 1.4.244 or newer. Set Git ref to main, add the source, then install and enable im Theme Collection. Install Inter and JetBrains Mono using their official font packages on that laptop.

Copy these official font package URLs into your browser. Orca blocks link navigation inside plugin panels.

https://github.com/rsms/inter https://github.com/JetBrains/JetBrainsMono
Reusable settings reference

A checklist to copy between laptops. Orca does not import this file as global settings.

Orca keeps plugin installation and consent dialogs in its built-in security colors. These independent palette adaptations include source and author notices with the package. The public theme API cannot change pane geometry, tab underline colors independently of text, toolbar layout, global icon sets, those dialogs, or syntax highlighting. Tab and worktree previews use the installed host’s color formulas; this is not a native app screenshot. Fonts and host preferences must be selected separately.

# im themes implementation plan

Goal: deliver reference-inspired warm dark and neutral light palettes with matching terminals and Material file icons; rename existing choices to im names and consolidate redundant variants.

Use the existing JSON theme contract and setup preview. Use layered surfaces in all themes and a main selection/focus accent. Keep existing contribution IDs stable except islands-darcula, whose canonical replacement is classic-dark. Consolidate byte-identical icon assets by updating all mappings and preserving source aliases in provenance. Keep legacy and modern packaging because they target different host contracts.

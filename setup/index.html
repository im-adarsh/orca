Illustrative layout · Actual palette values
For one consistent look

Every theme uses related shades for sidebars and raised panels, a clear selection accent, and matching editor and terminal surfaces. Use the same app and terminal theme name. Set background opacity and active/inactive pane opacity to 100%, choose Default for Left Sidebar Appearance, and clear terminal Color Overrides in both modes.

Settings to reuse on each laptop

Interface & editor

  • IDE font: Inter Variable or Inter
  • Editor font: JetBrains Mono
  • Left Sidebar Appearance: Default
  • Minimap: Off
  • Word wrap: On

Terminal

  • Font: JetBrains Mono, 14 px
  • Weight: 400; bold: 700
  • Line height: 1.2
  • All background/pane opacity: 100%
  • Cursor: bar; blink: On
  • Window blur: Off

Chat & navigation

  • Match terminal interface: On
  • Chat width: Wide
  • Chat contrast: 100%
  • Project: Cmd/Ctrl+Alt+1
  • Git: Cmd/Ctrl+Alt+9
  • Search: Cmd/Ctrl+Alt+Shift+F

Theme pairing

  1. In Appearance, select the app theme you want.
  2. Enable separate light and dark terminal themes. Put New UI Dark in the dark slot and New UI Light in the light slot as a starting pair.
  3. Select the same theme name in the slot matching its mode. Islands Light, Classic Light, New UI Light, Matte, and Paper use the light slot. All other themes use the dark slot.
  4. After updating the plugin, reselect the terminal theme to refresh its saved palette. Empty color override fields mean “use the selected theme”; a black empty picker swatch does not mean the theme is black.

Install on another laptop

Add this source under Settings → Plugins → Marketplace sources:

https://github.com/im-adarsh/orca.git

Requires Orca 1.4.244 or newer. Set Git ref to main, add the source, then install and enable GoLand Style for Orca. Install Inter and JetBrains Mono using their official font packages on that laptop.

Copy these official font package URLs into your browser. Orca blocks link navigation inside plugin panels.

https://github.com/rsms/inter https://github.com/JetBrains/JetBrainsMono
Reusable settings reference

A checklist to copy between laptops. Orca does not import this file as global settings.

Orca keeps plugin installation and consent dialogs in its built-in security colors. These independent palette adaptations include source and author notices with the package. The public theme API cannot reproduce Islands rounded pane geometry, Classic toolbars, global icon sets, those dialogs, or Go syntax highlighting. Fonts and host preferences must be selected separately.
